# Customer Sentiment Analyzer

A Python-based web application built using Streamlit.

## Features
- Single Review Sentiment Analysis
- Bulk CSV Analysis
- Positive, Negative and Neutral Classification
- Sentiment Dashboard
- Pie and Bar Charts
- Customer Feedback Keywords
- Customer Satisfaction Indicator
- CSV Report Download
- PDF Report Download

## Technologies
- Python
- Streamlit
- Pandas
- TextBlob
- Plotly
- ReportLab

## Run Application
streamlit run app.py
